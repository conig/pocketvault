Offline & installation

After a successful download, reading and search work offline. On Android, use Chrome’s menu → Add to home screen / Install app. Refresh runs on opening when connected; it does not run while the app is closed. Images are cached when viewed. Only work, personal, cooking, and codex folders are included.
